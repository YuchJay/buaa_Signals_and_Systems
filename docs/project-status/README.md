# 项目进度跟进

这个目录用于在新对话或新维护者接手时快速恢复上下文，不代替正文写作规范。

- `CURRENT.md`：唯一的当前状态入口，记录已完成内容、工作区状态、待办和验证结果。
- `DECISIONS.md`：记录长期有效的结构、编号、绘图和资料处理约定。

维护规则：

1. 每次完成正文、目录结构、环境或构建配置修改后更新 `CURRENT.md` 的日期和相关条目。
2. 已解决的问题从“待确认事项”中移除；必要时将结论写入 `DECISIONS.md`。
3. 不在这里复制长篇正文或完整终端日志，只记录足以继续工作的结论和命令。
4. Git 提交后更新 `CURRENT.md` 中的基线提交；未提交改动必须说明用途和归属。
