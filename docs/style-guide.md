# 写作规范

## 语言风格与去 AI 化

正文采用自然、克制的教材语气，直接说明对象、条件和结论。每次新增或改写正文、例题后，都要按 `humanizer-zh` 技能审校；这是交付前的固定步骤。

- 少用模板化开场和总结，不写“本章先回答一个核心问题”“这正是……的基础”“换句话说”等空泛承接。
- 控制“不是……而是……”“并非……而是……”“不仅……而且……”等对举句式。数学定义、反例或易错辨析确实需要对照时可以保留，不作机械禁用。
- 删去“至关重要”“关键作用”“深入理解”等泛化评价。能用对象、条件或计算结果说明的，不另加评价。
- 连接词按逻辑需要使用，避免连续以“因此”“因而”“此外”“最后”起句。长短句交替，段落不必都以总结句收尾。
- 保留教材所需的严谨性。去 AI 化只改表达，不改公式、定义、判据、适用条件和必要结论。
- 成稿须独立成立。正文、例题、图注及说明中禁用“原笔记”“笔记中”“原稿写道”等编写来源或整理过程措辞，也不能换成“资料中”“手稿中”等同义说法。直接写出知识、条件和结论；来源路径、页码及辨读差异放在内部文档或不参与排版的源码注释中。正常的文献引用和文内交叉引用可以保留。

## 章节组织

每章交代讨论对象和必要的先修知识，再按“定义 → 直觉 → 推导/定理 → 例子 → 易错点 → 小结与关联”的顺序组织。只保留对理解有帮助的层级，通常不超过 `\subsection`。

每节回答一个明确问题。若一段内容不能说明“它解决什么问题、依赖什么、结论在何种条件下成立”，先不要收录。

## 内容类型

- `definition` 给出可检查的精确定义；术语首次出现时同时给出英文。
- `intuition` 解释为什么这样定义、图像上如何理解，不重复定义原句。
- `theorem` 写清前提与结论；证明只保留关键逻辑，机械计算可放例题。
- `example` 是正文中的简短“示例”，服务于一个明确概念，不承担章后题集的编号。
- 典型信号的变换对、基本性质等核心结论应设独立小节或明确的结论段，给出公式、条件和必要推导，不降为 `example`。示例用于应用这些结论的具体计算。典型变换除图形非常显然者外，须配时域和频域图；复频谱根据需要画实虚部或幅相谱，标清零点、冲激权重及未定义的相位。
- `workedexample` 是章后例题的题面；其后依次使用不编号的 `solution` 和 `technique` 写解答与可迁移的做题方法。
- `remark` 收纳旁支联系、符号差异和非主线补充。
- `pitfall` 用“原误解 → 错因 → 正确认识 → 触发检查”的格式记录易错点。

## 章后例题集

- 例题文件放在 `examples/`，文件名与对应章节一致，并在 `main.tex` 中紧接该章正文载入。没有例题时不建立空标题。
- 每道题按“题面 → 题图 → 解答 → 答案图 → 解题技巧”组织。题面必须给足条件；若原资料只给图，应把可可靠读出的关键点或样值补成文字，避免答案依赖图像像素。
- `workedexample` 按章独立编号，标签使用 `ex:` 前缀。正文中的 `example` 使用 `eg:` 前缀，避免两类内容混淆。
- 解答要保留决定方法的中间步骤，尤其是变量代换、关键点映射和适用条件；不要只给最终结果，也不要堆叠没有解释的代数运算。
- `technique` 只总结能够迁移到同类题的方法。原稿批注中的口诀可以保留，但须同时给出更稳妥的判断方式。
- 题图与答案图分开制作，并遵守正文插图的引用规则。绘图脚本放在 `scripts/figures/` 的对应章节目录，生成文件放在 `figures/` 的对应章节目录。
- 手写资料无法确认的字符、端点或图形细节，先采用不影响主方法的最合理解释，并记入 `docs/source-questions.md`；不得把推断写成已经确认的原文。

## 课程解法与应试计算

- 课堂笔记决定例题的主解法、计算顺序和展开程度。整理时保留其中适合手算的列表、图解、逐点求积、分段计算及口诀，并说明下标或边界的判断依据。
- 教材用于核对公式、适用条件和计算结果，也可补充第二种解法。简洁通式、抽象表示和性质推导放在具体计算之后，不得替代课程已有的做题过程。
- 短有限序列的离散卷积须先求首尾下标，再翻转、平移、按同一横坐标对齐。输出范围内的每个整数下标都要列出参与相乘的样值及其和，包括结果为零的下标；序列内部的零样值保留位置。图或表要能看出乘积的配对关系。
- 无限序列无法逐项穷举时，先展开前几个输出样值，说明每次平移新增或移去哪些乘积，再确定一般求和范围并归纳通式。
- 例题取舍以方法覆盖为依据。含负下标、正负幅度、内部零样值、边界变化的题不能只留下答案；相近题可以合并，但应保留各自的易错步骤。

## 公式与引用

- 只有后文会引用、代表关键结论或需要讨论条件的公式才编号；行内公式和一次性计算不编号。
- 标签紧跟被标记对象，格式统一为 `chap:`、`sec:`、`eq:`、`fig:`、`tab:`、`def:`、`thm:`、`eg:`、`ex:`；其中 `eg:` 用于正文示例，`ex:` 用于章后例题。
- 正文使用 `\cref{...}`，不要手写“式 (3.2)”等易失效编号。
- 图、表必须在正文中被引用，并说明它支持什么观察或结论。

## 重点标注

正文与例题统一使用四类标注，都由 `config/commands.tex` 中的宏实现。四类分工固定，对应四种复习动作，便于通读时按需要快速定位。

| 标注 | 宏 | 标什么 | 读者动作 | 密度 |
| --- | --- | --- | --- | --- |
| 标红 | `\red{...}` | 结论与判据 | 记住 | 每节 2～6 处 |
| 标蓝 | `\blue{...}` | 前提与检查项 | 用前核对 | 每节 0～3 处 |
| 加粗 | `\keyterm{...}` | 术语与名称 | 认名词 | 每节 1～3 处 |
| 黄底 | `\hl{...}` | 做题步骤与口诀 | 照做 | 每章 3～8 处 |

共同约定：

- 只标文字短语，不标公式：四类标记内都不得出现 `$...$` 或数学命令，行内数学保持在标记范围之外；编号公式整体保持黑色。
- 标记之间不嵌套、不重叠，同一短语只归一类。
- 密度按节计（`\section` 或 `\subsection` 各记一节），某一类可以为 0，但一节里四类全无通常说明有漏标。

### 标红：结论与判据

标出复习时值得停留的知识要点：结论、等价判据、量与量之间的关系、易混区别、易错认识，以及承上启下的伏笔。每处 3～16 字，不整句、整段标红。

- 标知识本身，不标前提描述、推导过程和计算步骤；定义框内只在关键结语点缀。
- 同一组并列判据可用关键词对标（如“压缩/扩展/翻转”），同义要点不在两处重复。
- 结论成立的条件与适用范围改用蓝色，做题的动作口令改用黄底，不再留在红色里。

### 标蓝：前提与检查项

标出结论成立所需的条件、适用范围和成立边界，以及使用前应当先做的核对动作（“先检查……”“……是否满足……”）。每处 3～16 字。

- 与红色配合：红标结论，蓝标同一条结论的前提，两者相邻时保持两个独立标记，不合并成一处。
- 判断动作限于核对、筛选和排除，不产生计算结果；凡是要动手算的先后顺序，改用黄底。
- 边界提醒如“等号时检查端点”“非带限信号不能照套”属于适用范围，用蓝色。

### 加粗：术语与名称

标出正式术语、被定义对象、变换与性质的名称，形成可检索的名词表。

- 每节 1～3 处；同一术语全书只加粗一次，取首次出现处，定义框或被定义的段落优先，后文重复出现不再加粗。例题集通常没有新术语，不设加粗指标。
- 术语按“中文（English）”首次给出时，加粗整个“中文（English）”；通行缩写（LTI、DTFT）可单独加粗。
- 不用于强调语气或句子重心，一句话里最多一处。

### 黄底高亮：做题步骤与口诀

标出做题时手上照做的计算顺序、逐点操作、速判口令和课程口诀，如“翻转、平移、相乘、求和”“先定位、再代入”。

- 每章 3～8 处；例题集里每道题 1～2 处，通常落在 `technique` 的口诀句。
- 只标动作口令：结论用红，核对条件用蓝，都不进黄底。
- 标记长度控制在 14 字以内；长口令沿顿号或逗号拆成两处短的。色块逐字断开、可随正文跨行，不会顶出行宽。

## 术语与符号

- 中文术语首次出现时写作“中文（English）”，之后以中文为主；通行缩写如 LTI、CTFT、DTFT 可保留。
- 全局数学符号只在 `config/commands.tex` 定义；局部临时符号在首次出现处解释。
- 每个变换首次使用时明确采用的正逆变换约定、频率变量和收敛条件。
- 同一对象跨章节保持同一记号；确需改变时明确给出映射关系。

## 防止退化为讲义抄写

每个知识点至少加入一种个人加工：自己的直觉解释、与旧知识的联系、一个反例、适用条件检查，或对首次误解的修正。加工应帮助读者理解和复现课程解法，保留具体计算步骤。引用教材时先合上资料复述逻辑，再对照纠错；无法复述的段落标记为待理解。

资料使用顺序如下：

1. 用 `materials/chapter*.pdf` 确定本轮施工边界、知识点顺序、红字判据、课程记号和例题主解法，保留清晰的手算过程；
2. 查阅 `materials/` 中的奥本海姆《Signals and Systems》，核对定义、术语、公式成立条件与推导；补充例题须服务于课程方法的练习；
3. 若教材与课堂笔记存在实质差异，正文先采用课程口径，同时记录差异并等待确认；不得把两个版本直接拼接成一个未经说明的结论；
4. 教材内容须转化为本项目的中文表述，不复制长段原文，也不照搬其章节结构。

章节完成前自检：能否说出核心问题、为何选择该表示、结论的适用条件、一个典型错误，以及它与前后章节的联系。
