# 第二章插图

本目录中的 PDF 均由 [`scripts/figures/ch02_signals/generate.py`](../../scripts/figures/ch02_signals/generate.py) 生成：

- `time-transformations.pdf`：时移、尺度变换与时间反转
- `even-odd-decomposition.pdf`：信号的奇偶分解
- `continuous-step-impulse.pdf`：连续时间阶跃与冲激
- `discrete-step-impulse.pdf`：离散时间阶跃与冲激
- `sampling-functions.pdf`：`Sa` 与归一化 `sinc`

不要直接编辑生成的 PDF。需要修改曲线、标注或配色时，请修改绘图脚本后重新运行。
